Générer les clés de notification (VAPID)

Ces deux clés permettent à ton serveur Supabase d'envoyer des notifications. Tout est calculé dans ton navigateur, rien n'est envoyé nulle part.

Clé publique

À coller dans config.js (VAPID_PUBLIC_KEY) et dans les secrets Supabase (VAPID_PUBLIC_KEY).

Clé privée

À coller uniquement dans les secrets Supabase (VAPID_PRIVATE_KEY). Ne la mets jamais sur GitHub.

Génère les clés une seule fois. Si tu les changes plus tard, chaque téléphone devra réactiver les notifications.
